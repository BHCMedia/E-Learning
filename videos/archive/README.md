## Hard rules for anything reused from this archive

- **Filmed footage must not be reused** in any final Dementia Care video.
- **The old indigo/cyan styling must not be reused.** The active palette is navy/teal/white/light-grey per `DESIGN.md`.
- **The old 25 fps settings must not be reused.** The active spec is 30 fps.
- Code patterns (e.g. the Lucide-icon-in-HyperFrames integration technique) may be reviewed for engineering reference only, restyled to the new palette and iconography rules before any reuse.
